# まえだ歯科 ランディングページ

和歌山市にある「まえだ歯科」の1ページ完結型ランディングページです。
電話問い合わせとGoogleマップでの経路検索へ誘導することを目的としています。

## ファイル構成
```
20260621_まえだ歯科/
├── index.html    # メインのHTMLファイル
├── style.css     # スタイリング（Vanilla CSS）
├── script.js     # アニメーション、メニュー制御等
├── images/       # 画像ディレクトリ（プレースホルダー等配置用）
└── README.md     # このファイル
```

## デザインコンセプト
「精密」「誠実」「静けさ」「信頼」を感じさせる、上質なクリニックや建築事務所のようなデザイン。
- 余白を広く確保
- 色数を制限（オフホワイト、チャコールグレー、深いグリーン）

## 運用前の確認事項

### 画像の差し替え（プレースホルダーについて）
現在、画像はCSSのプレースホルダー（グレー背景に文字）で実装しています。本番環境にデプロイする前に、以下の画像を準備して差し替えてください。

推奨サイズ（参考）：
- ファーストビュー画像 (`.hero__image`): 1920x1080 (PC/SPでトリミングされることを想定)
- 特徴カード画像 (`.feature-card__image`): 600x400 (アスペクト比 3:2)
- 院長写真 (`.director__image`): 800x1000 (アスペクト比 4:5)
- 院内ギャラリー画像 (`.gallery__image`): 800x600 (アスペクト比 4:3)
- OGP画像 (`og:image`): 1200x630
- ファビコン: `favicon.ico`, `apple-touch-icon.png`

※ 各画像のパスは `index.html` または `style.css` に記述されているパスに適宜変更してください。

### OGP・SEOタグの修正

### その他の確認事項

## 技術仕様
- **HTML5**: セマンティックなマークアップ、Microdata / JSON-LD による構造化データ。
- **CSS3**: カスタムプロパティ（CSS変数）を使用したVanilla CSS。BEMに類似した命名規則を使用。
- **JavaScript**: jQuery非依存（Vanilla JS）。スムーススクロール、IntersectionObserverによるフェードインアニメーション。`prefers-reduced-motion` 対応済み。
